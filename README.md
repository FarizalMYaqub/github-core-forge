A standalone GitHub-compatible git forge in one Node process: git smart HTTP (clone, fetch and push over upload-pack v2 and receive-pack v0), REST v3 repositories, issues, pull requests and contents, GraphQL v4 and an MCP endpoint, all over its own in-memory store with no dependencies and no outside service.

## Run it

```sh
node --experimental-strip-types main.ts
```
